# 2.0
Создание проекта:
- Теперь при создания нового проекта вместо модального окна открывается новый экран
- В нём, как и раньше, можно создать новый проект, либо же импортировать уже существующий из файла (смотреть раздел Импорт и экспорт проекта)

Экран настроек:
- Добавлен экран настроек всего приложения
- На данный момент в нём есть только кнопка экспорта логов (для разработчиков)
- Экран открывается в любом месте приложения при нажатии на шестерёнку (справа сверху)

Экрана настроек проекта:
- Настройки проекта теперь открываются при нажатии на блок информации (вкладка Главная внутри проекта)
- Экран настроек проекта разделён на 2 вкладки: Редактирование и Действия
- Вкладка Редактирование отвечает за всё то, что было раньше в экране настроек
- Вкладка Действия позволяет экспортировать проект в файл, либо же удалить его

Импорт и экспорт проекта:
- Проект можно сохранить в файл .mblp
- Кнопка экспорта расположена в настройках проекта в новой вкладке Действия
- Кнопка импорта расположена в экране создания проекта

Доработка галереи:
- Добавлены анимации, движения стали плавнее
- Добавлен автозум при двойном клике
- Исправлена загрузка сразу нескольких файлов
- Оптимизирован предосмотр изображений из экрана проекта

Прочее:
- Значительно уменьшен вес приложения
